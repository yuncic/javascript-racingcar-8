# javascript-racingcar-precourse
## 1. 프로그램 구조

- **App.js**  
  프로그램 실행의 시작점.  
  사용자 입력 → 경주 실행 → 결과 출력 전체 흐름을 관리한다.

- **Car.js**  
  자동차 객체를 정의한다. (이름, 위치, 전진 기능 포함)

- **Race.js**  
  경주 전체 로직을 관리한다. (라운드 실행, 우승자 계산)

- **InputView.js**  
  사용자 입력을 처리한다. (자동차 이름, 시도 횟수)

- **OutputView.js**  
  출력 결과를 담당한다. (각 라운드 결과, 우승자 출력)

- **Validator.js**  
  입력값 검증 로직을 관리한다. (이름 유효성, 횟수 유효성)

- **RandomUtil.js**  
  난수 생성 기능을 분리한다. (`MissionUtils.Random` 사용)

## 2. 기능 요구 사항

### 자동차 이름 입력
- [ ] 사용자로부터 자동차 이름을 입력받는다.  
- [ ] 이름은 쉼표(,)로 구분한다.  
- [ ] 각 이름은 5자 이하만 가능하다.  
- [ ] 잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료한다.

### 시도 횟수 입력
- [ ] 사용자로부터 시도 횟수를 입력받는다.  
- [ ] 시도 횟수는 양의 정수만 가능하다.  
- [ ] 잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료한다.

### 자동차 전진
- [ ] 각 자동차는 0~9 사이의 랜덤 값을 받는다.  
- [ ] 랜덤 값이 4 이상이면 전진한다.  
- [ ] 전진 시 자동차의 위치를 `-`로 표시한다.

### 경주 진행
- [ ] 입력받은 횟수만큼 경주를 진행한다.  
- [ ] 매 시도마다 각 자동차의 상태를 출력한다.

### 우승자 계산
- [ ] 가장 많이 전진한 자동차를 찾는다.  
- [ ] 우승자가 여러 명일 경우 쉼표(,)로 구분한다.  
- [ ] `"최종 우승자 : pobi, jun"` 형식으로 출력한다.

### 예외 처리
- [ ] 잘못된 입력 시 `[ERROR]` 메시지를 출력한 뒤 예외를 발생시킨다.  
- [ ] `process.exit()`는 사용하지 않는다.
