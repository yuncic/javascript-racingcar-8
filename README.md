# 기능할 구현 목록

## 1. 기능 요구 사항

### 자동차 이름 입력
- [ ] 사용자로부터 자동차 이름을 입력받는다.  
- [ ] 이름은 쉼표(,)로 구분한다.  
- [ ] 각 이름은 5자 이하만 가능하다.  
- [ ] 잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료한다.

### 시도 횟수 입력
- [ ] 사용자로부터 시도 횟수를 입력받는다.  
- [ ] 시도 횟수는 양의 정수만 가능하다.  
- [ ] 잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료한다.

### 자동차 전진
- [ ] 각 자동차는 0~9 사이의 랜덤 값을 받는다.  
- [ ] 랜덤 값이 4 이상이면 전진한다.  
- [ ] 전진 시 자동차의 위치를 `-`로 표시한다.

### 경주 진행
- [ ] 입력받은 횟수만큼 경주를 진행한다.  
- [ ] 매 시도마다 각 자동차의 상태를 출력한다.

### 우승자 계산
- [ ] 가장 많이 전진한 자동차를 찾는다.  
- [ ] 우승자가 여러 명일 경우 쉼표(,)로 구분한다.  
- [ ] `"최종 우승자 : pobi, jun"` 형식으로 출력한다.

### 예외 처리
- [ ] 잘못된 입력 시 `[ERROR]` 메시지를 출력한 뒤 예외를 발생시킨다.  
- [ ] `process.exit()`는 사용하지 않는다.

## 2. 테스트 코드 (Jest)
- [ ] 자동차 전진 조건 테스트 (4 이상일 때만 전진)  
- [ ] 자동차 이름 검증 테스트 (5자 초과 시 에러 발생)  
- [ ] 시도 횟수 검증 테스트 (음수나 문자가 입력될 경우 에러 발생)  
- [ ] 경주 결과 테스트 (정상적으로 결과 출력되는지 확인)  
- [ ] 공동 우승자 테스트

## 3.디렉터리 구조

src/
 ├─ 📄 index.js             # 프로그램 진입점
 ├─ 📄 App.js               # 전체 실행 흐름 제어 (입력 → 경주 실행 → 결과 출력)
 ├─ 📄 Race.js              # 경주 로직 관리 (라운드 진행, 우승자 계산)
 ├─ 📄 Car.js               # 자동차 객체 정의 (이름, 위치, 전진 기능)
 ├─ 📄 InputView.js         # 사용자 입력 처리 (자동차 이름, 시도 횟수)
 ├─ 📄 OutputView.js        # 출력 담당 (라운드별 결과, 우승자 표시)
 ├─ 📄 Validator.js         # 입력값 검증 (이름 형식, 횟수 유효성)
 ├─ 📄 constants.js         # 상수 및 메시지 정의
